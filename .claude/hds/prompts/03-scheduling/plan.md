Implement the pure scheduling package with two solvers behind one signature: the greedy baseline from HDS 1.0 and OR-Tools CP-SAT with a 20 second cap and an `optimal` flag. Asynchronous jobs with statuses queued, running, succeeded, failed, run by a worker (use a Postgres-backed queue, no extra broker). Property-based tests with Hypothesis proving the hard rules hold for any generated input, and a benchmark comparing greedy and CP-SAT. Endpoints: POST /schedule-jobs, GET /schedule-jobs/{id}, POST /schedule-jobs/{id}/accept.
